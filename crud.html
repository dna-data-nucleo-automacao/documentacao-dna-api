⚙️ Funcionamento Geral do CRUD

Alteração de Registro (PUT)

PUT

BaseRoute/cadastro/:tabela/:id
Parâmetros:
  • :tabela - Nome da tabela
  • :id - ID do registro a ser alterado
Exemplo - Alterar Cliente:

Rota: BaseRoute/cadastro/CLIENTE/1

Body JSON:

{ "codigo": 2, "nome": "fulano das tantas", "cpf": "00000000000" }

Criação de Registro (POST)

POST

BaseRoute/cadastro/:tabela
Parâmetros:
  • :tabela - Nome da tabela
Exemplo - Criar Cliente:

Rota: BaseRoute/cadastro/Cliente

Body JSON:

{ "nome": "beltrano das quantas", "cpf": "11111111111", "rua": "av. do ping pong" }

Exclusão de Registro (DELETE)

DELETE

BaseRoute/cadastro/:tabela/:id
Parâmetros:
  • :tabela - Nome da tabela
  • :id - ID do registro a ser deletado
Observação: Não é necessário enviar nada no body da requisição.
