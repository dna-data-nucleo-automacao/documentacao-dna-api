📦 Rotas de Produto

Produtos com Múltipla Filtragem

GET

BaseRoute/consulta/produto/?page=:pagina&limit=:quantidade&filtro1=:filtro1&filtro2=:filtro2
Filtros disponíveis para busca:
  • descricao - Descrição do produto
  • inativo - S ou N
  • codalternativo - Código alternativo
  • codigo - Código do produto
  • codbarras - Código de barras
  • ncm - Código NCM
  • cest - Código CEST
  • estoque - Quantidade em estoque
  • cimportado - S ou N (Importado)
  • tipo - "mao de obra" ou "peca"
  • imposto - Descrição do imposto
  • fornecedor - Razão social do fornecedor
  • grupo - Descrição do grupo
  • subgrupo - Descrição do subgrupo
  • marca - Descrição da marca
  • codnum - Código numérico
Exemplo:
BaseRoute/consulta/produto/?page=1&limit=10&description=chicote

Produtos Similares

GET

BaseRoute/consulta/similares/?page=:pagina&limit=:quantidade&codigo=:codigo_peca
Parâmetros:
  • codigo - Código da peça para buscar similares
Exemplo:
BaseRoute/consulta/similares/?page=1&limit=10&codigo=12345
