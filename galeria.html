🖼️ Rotas de Galeria

Cadastro de Arquivos

POST

BaseRoute/cadastro/galeria
Parâmetros do Body:
  • nome_pasta - Nome da pasta
  • id_pasta - ID do registro
  • imagens - Array de imagens com extension e base64
Exemplo de Body JSON:
{ "nome_pasta": "veiculo", "id_pasta": "30", "imagens": [ { "extension": "png", "base64": "base64 da foto1" }, { "extension": "pdf", "base64": "base64 da foto2" } ] }

Consulta de Arquivos

GET

BaseRoute/consulta/galeria/:nome_pasta/:id_pasta
Parâmetros:
  • :nome_pasta - Subpasta de Galeria que deseja entrar
  • :id_pasta - Subpasta de nome_pasta
Exemplo:
BaseRoute/consulta/galeria/veiculo/30

Exclusão de Arquivos

DELETE

BaseRoute/consulta/galeria/?nome_pasta=:nome_pasta&id_pasta=:id_pasta&nome_arquivos=:nome_arquivos
Parâmetros:
  • nome_pasta - Subpasta de Galeria que deseja entrar
  • id_pasta - Subpasta de nome_pasta
  • nome_arquivos - Nomes dos arquivos separados por vírgula
Exemplo:
BaseRoute/consulta/galeria/?nome_pasta=veiculo&id_pasta=30&nome_arquivos=arquivo1,arquivo2,arquivo3
Importante:

NÃO dar espaço entre as vírgulas nos nomes dos arquivos.
