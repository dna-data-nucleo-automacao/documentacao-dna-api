🔧 Rotas de Ordem de Serviço

OS com Múltiplos Filtros

GET

BaseRoute/consulta/os/capa/?page=:pagina&limit=:quantidade&filtro1=:filtro1&filtro2=:filtro2
Filtros disponíveis para busca:
  • mecanico - Nome do mecânico
  • placa - Placa do veículo
  • numos - Número da OS
  • situacao_inicio e situacao_fim + tipo_data (ABERTURA ou SITUACAO)
  • situacao - Situação da OS
  • tipoos - Tipo da OS
  • modelo - Modelo do veículo
  • tipo_cliente - F (Física) ou J (Jurídica)
  • proprietario - Nome do cliente
  • dinamico - Parte do modelo e/ou placa
Exemplo:
BaseRoute/consulta/os/capa/?page=1&limit=20&plate=XXX 1234&mechanic=Rogerio

Cadastro de OS Completa (CAPA + ITENS)

POST

BaseRoute/cadastro/os/completa
Observação:

Esta rota é utilizada apenas para O.S feita do "zero". O body deve conter a capa da OS e um array de itens.

Exemplo de JSON:
{ "capa": { "placa": "XXX1234", "codprop": 10, "mecanico": 1, "tipoos": 1, "situacao": 1 }, "itens": [ { "codigo_peca": 100, "quantidade": 2, "valor_unitario": 50.00 }, { "codigo_peca": 101, "quantidade": 1, "valor_unitario": 150.00 } ] }

Alteração de OS Completa (CAPA + ITENS)

PUT

BaseRoute/cadastro/os/completa/:codigo_da_OS
Parâmetros:
  • :codigo_da_OS - Código da OS a ser alterada
Exemplo de JSON:
{ "capa": { "mecanico": 2, "situacao": 3 }, "itens": [ { "codigo": 1, "quantidade": 3, "valor_unitario": 55.00 } ] }
